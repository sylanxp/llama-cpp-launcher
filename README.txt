========================================
  Llama.cpp Launcher 部署说明
========================================

【运行要求】
- Windows 11
- Node.js 18 或更高版本（下载地址：https://nodejs.org）

【快速启动】
1. 确保 Node.js 已安装
2. 双击 start.bat 启动服务
3. 浏览器会自动打开 http://localhost:3000
4. 如浏览器未自动打开，请手动访问 http://localhost:3000

【功能说明】
- 硬件信息：自动检测 CPU、内存、GPU
- 路径配置：设置 llama.cpp 和模型目录
- 模型选择：扫描并选择主模型和视觉模型
- 推理参数：Context Size / ngl / 线程数 / Flash Attention / mlock
- 服务设置：监听模式（本地/局域网/自定义）、端口
- 自动重启：上下文溢出时自动重启服务
- 实时日志：查看服务运行日志

【注意事项】
- 首次使用请先在"路径配置"中设置 llama.cpp 目录
- 启动服务前请确保已选择主模型
- 启用 mlock 可能需要管理员权限运行
- 不要删除 db 文件夹中的数据库文件
