# 🚀 Llama.cpp Launcher

Llama.cpp Launcher 是一款为 `llama.cpp` 设计的专业桌面启动器，旨在通过图形化界面简化模型的部署、参数配置及服务维护。它提供了从硬件监测到自动化运维的全链路支持，让本地 LLM 的运行更加稳定且高效。

## ✨ 核心功能

### 🖥️ 硬件信息监测 (Hardware Info)
位于页面顶部的实时信息卡片，让用户在启动前快速评估资源状态：
- **处理器**：实时显示 CPU 型号、物理核心数及逻辑线程数。
- **内存**：显示总内存容量及当前操作系统的指令集架构。
- **显卡**：自动检测 GPU 名称及可用显存大小（兼容 `wmic` 与 `nvidia-smi`）。
- **交互**：提供一键刷新按钮，确保信息实时更新。

### 📁 路径与模型管理 (Path & Model Config)
提供直观的目录管理方案，彻底告别手动输入路径：
- **目录配置**：Llama.cpp 程序目录与模型存放目录均配备 **"浏览"** 按钮。
- **智能浏览窗口**：
  - **盘符检测**：Windows 环境下自动扫描并列出所有可用盘符（C: D: E: 等）。
  - **灵活跳转**：支持逐级进入子目录、手动输入路径快速跳转以及一键返回上级。
- **模型选择**：自动扫描指定目录，支持快速选择 **主模型 (Main Model)** 和 **视觉模型 (Vision Model)**。

### ⚙️ 推理参数精调 (Inference Parameters)
将复杂的命令行参数转化为简单的 UI 控件：
- **核心参数**：
  - `Context Size`：设置上下文窗口上限。
  - `ngl` (GPU Layers)：配置卸载到 GPU 的层数。
  - `线程数`：优化 CPU 推理并发。
  - `Flash Attention`：快速开启/关闭以提升推理速度。
- **🔒 内存锁定 (mlock)**：
  - 提供 `--mlock` 开关，锁定模型内存防止被操作系统交换到磁盘。
  - 带有风险提示：告知用户此操作可能需要管理员权限。

### 📡 服务设置与网络 (Service Settings)
灵活定义 API 服务的可访问范围：
- **监听模式**：
  - `本地` $\rightarrow$ `127.0.0.1` (仅本机访问，高安全性)。
  - `局域网` $\rightarrow$ `0.0.0.0` (允许同一网络下的其他设备访问)。
  - `自定义` $\rightarrow$ 允许用户手动输入特定 IP 地址。
- **端口配置**：自定义服务监听端口及附加启动参数。

### 🔄 自动化运维 (Auto-Restart)
针对“无限上下文”或长时间运行场景设计的自愈机制：
- **触发模式**：
  - `API 检测 (推荐)`：通过定时请求 `/health` 接口，若服务不可达则触发重启。
  - `日志关键词`：实时监测日志流，发现 `context limit` 或 `context full` 等关键词时立即重启。
- **精细化控制**：
  - 启用/禁用单选切换。
  - **重启延迟**：自定义停止服务后的重启等待秒数（默认 3 秒），防止频繁重启导致系统崩溃。
- **智能联动**：停止服务时，自动取消当前所有待执行的重启计时器。

### 📋 实时日志系统 (Service Logs)
提供一个完整的终端仿真窗口，用于监控后端状态：
- **实时输出**：同步显示 `llama.cpp` 的所有标准输出。
- **彩色高亮**：对不同级别的日志进行着色处理。
- **特殊标记**：自动重启触发时，日志中会以 **紫色高亮** 显示 `[auto-restart]` 标签。

## 🛠️ 技术细节

| 模块 | 实现方案 | 备注 |
| :--- | :--- | :--- |
| **硬件检测** | `wmic` (Windows) / `nvidia-smi` (NVIDIA) | 确保跨硬件兼容性 |
| **目录浏览** | 自定义递归文件系统遍历算法 | 支持盘符自动映射 |
| **健康检查** | HTTP GET `/health` $\rightarrow$ Timeout/Error $\rightarrow$ Restart | 毫秒级心跳监测 |
| **日志渲染** | 虚拟列表 + 正则表达式高亮 | 保证大数据量日志下不卡顿 |
